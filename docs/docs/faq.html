FAQ

Short answers to the questions that come up most.

Is MuffinEMU the same thing as Muffin?

No. MuffinEMU grew out of Muffin (kiddreads/cemu-ios-muffin) but is now its own emulator with its own bundle identifier (com.kiddreads.MuffinEMU), its own Cemu core, and its own releases. It installs next to Muffin rather than replacing it.

Do I need to own a Wii U?

To play encrypted retail games, yes — you need keys.txt dumped from your own console. Homebrew doesn't need it. MuffinEMU ships no keys, derives no keys, and has no way to obtain a key it wasn't given.

Which install method should I use?

SideStore, AltStore, or LiveContainer if you want the app to re-sign itself with your own Apple ID. TrollStore or a jailbroken device if you want the JIT entitlements embedded directly in the IPA. See Installation for the full breakdown.

Does it support every Wii U game?

Not confirmed — broad compatibility hasn't been systematically tested. MuffinEMU boots real titles from an imported library on real hardware; a full, confirmed playthrough of a retail title on this exact build is still pending, and this documentation will say so plainly the day one lands.

Can I use a physical controller?

Basic controller input works, but it hasn't been tested systematically across MFi and Bluetooth controllers the way the on-screen pad has.

Is there a paid version?

No StoreKit purchase exists in the app. A free code unlocks 3 "Pro" app icon themes; every other feature — save states, graphic packs, DLC/update import, all 28 non-Pro themes, Melo-Controller, all 20 controller skins — is free with no gate at all. See Themes & Icons.

What license is MuffinEMU under?

MuffinEMU's own source is MPL-2.0, like Cemu and MeloCafe. Because Melo-Controller (GPL-3.0) is linked into every build — whether or not its toggle is on — a MuffinEMU IPA as a whole is distributed under GPL-3.0, with the MuffinEMU repository as its source.

Does dual-screen TV output work?

Not confirmed yet. The code path is written against the real display API but has never been exercised with a second display actually attached — see External display routing for the honest breakdown.

Where do I report a bug?

github.com/kiddreads/MuffinEMU/issues — see Troubleshooting for what to attach.
