Features overview

Everything the app side does, grouped by area. Deep dives on Screen Layout, Save States, Controls and Themes each get their own page — this one is the map.

Library & importing

  • Library & importer — brings in your own ROM dumps; homebrew is unaffected by keys either way.
  • keys.txt handling — drop a keys.txt from your own Wii U into the Files app or import it in Settings; nothing is bundled.
  • Decrypt-to-Files and WUA — exports a decrypted copy of an encrypted disc image to Documents/Decrypted/<gameID>/ as either a raw source or a single WUA file, leaving your original encrypted dump completely untouched.
  • DLC and update install — imports a DLC or update dump into the same Documents/mlc tree the engine's own title scanner already reads, with title-ID matching so a freshly-imported title is picked up before the base game's next launch, and removal via long-press.
  • Graphic packs — browse and toggle packs from Documents/mlc/graphicPacks/; drop in a folder with its own rules.txt, the same layout desktop Cemu uses.

On-screen play

  • The measured Wii U GamePad, hide-controls, comfort controls, and 20 controller skins.
  • Melo-Controller — an alternative touch pad with its own layout editor, as a toggle.
  • Screen Layout — Single Screen, Adaptive, or GamePad-inset, plus routing to a genuine second display.
  • Save States — 4 numbered slots per game, alongside your normal in-game saves.

Look & feel

  • 31 app icons and matching themes — 3 unlocked by a free code, everything else free.

Diagnostics

  • In-app launch log — drains the engine's own log ring live at 10 Hz while a title boots, and says so plainly if the ring evicted lines before the viewer could read them, rather than silently showing a tidy but incomplete list.
  • Crash and memory trail — checkpoints are appended to Documents/CemuCrashLog.txt via a raw synchronous write, so the trail survives even an abrupt, uncatchable process termination (a GPU driver panic, for instance) — the file to share when reporting a crash.

Under the hood

The renderer is Metal, native to this port rather than a Vulkan translation layer, with an optional Vulkan (MoltenVK) path for titles that prefer it. GPUs without mesh shader support — the A12Z and similar — emulate geometry shaders and RECTS primitives with compute passes instead, and decode BC-compressed textures on the CPU rather than in hardware. The CPU side runs a multi-core PowerPC interpreter with a predecoded instruction cache; an AArch64 recompiler is present and can take over when a JIT enabler is attached (see JIT requirements).

Every build carries a curated set of fixes ported from upstream Cemu on top of the core, plus MuffinEMU's own — real crashes and hangs get tracked and fixed as they're found rather than papered over.
