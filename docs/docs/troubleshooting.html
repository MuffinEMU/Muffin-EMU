Troubleshooting

Common snags, and what's actually going on under each one.

An encrypted game does nothing when I try to launch it

You need keys.txt, dumped from your own Wii U, in the keys folder MuffinEMU creates in the Files app (or imported via Settings). Without it, encrypted games simply won't run — homebrew and unencrypted content are unaffected either way. A file dropped in mid-session is picked up before the next key read, no relaunch needed.

The game seems to be running on the interpreter, not the recompiler

The recompiler needs both a JIT enabler attached (StikJIT, or SideStore/LiveContainer's own attach) and the recompiler switch on in Settings > CPU. Missing either one, MuffinEMU falls back to the interpreter automatically — Settings always states which mode a given launch got and why, so check there first rather than guessing.

A game glitches, desyncs, or crashes

Try Settings > CPU > "Favour accuracy" — it's slower, but trades speed for correctness on titles that don't get along with the fast path. Restart the game after changing any CPU setting; it doesn't apply mid-session.

A save state won't load

This is refused on purpose, not a bug, if the currently running title's ID, thread list, or memory layout don't match the save exactly — which happens the moment you quit or relaunch the game, or restart the app. A save state only loads back into the exact same running instance it was taken from; see Save States for the full reasoning. For anything that needs to survive between sessions, use the game's own normal saves.

After loading a save state, something looks briefly wrong on screen

Expected: a texture or shader that changed since the save may flash its old contents for a moment, until the game's own next draw call refreshes it. That's a visual glitch, not lost progress — see Save States for why GPU state is deliberately not part of what's captured.

TrollStore / an installer says the IPA is "not signed"

Expected for MuffinEMU-fakesigned.ipa — it's ad-hoc signed, which has no certificate or team ID, so most tools describe it that way. Use it for TrollStore or a jailbroken device. MuffinEMU.ipa is the plain unsigned build meant for SideStore/AltStore/LiveContainer, which re-sign it themselves at install. See Installation for which one you actually need.

Nothing shows up on my TV / second display

Honestly: true dual-screen output to a genuine second display has never been exercised on a device in practice — the code path exists and is written against the real API, but is expected to fall back to screen-mirroring behaviour (TV screen only, mirrored) rather than routing the TV and GamePad to separate displays. See External display routing for the honest breakdown of what is and isn't confirmed there.

Collecting logs before filing a bug

Two files matter: the running log.txt, and Documents/CemuCrashLog.txt — a checkpoint trail written with a raw synchronous write specifically so it survives even an abrupt process termination. If the app never got far enough to open a log at all, there may be no CemuCrashLog.txt to send; say so in your report rather than assuming one exists. Attach both when you can, and open an issue at github.com/kiddreads/MuffinEMU/issues.
