Themes & Icons

31 app icons, each with a matching colour theme. The data below is the real thing, not a placeholder palette.

How the themes are built

Bakery (Original) is the app's existing hand-tuned palette, kept as-is rather than re-derived. The other 30 are a systematic derivation from each icon's own real artwork: median-cut colour quantization picks a primary/secondary/accent triad from the icon, then fixed lighten/darken/desaturate formulas build the light and dark variant of each — the same relationships Bakery's own hand-tuned palette already used (lighten accents for dark mode, deepen and desaturate backgrounds, flip text from dark-on-cream to light-on-dark), just applied uniformly instead of judged one icon at a time. Every hex value traces back to a real pixel in that icon's actual art — none of it is invented.

Every UI colour in the app reads through these 14, via a trait-collection-adaptive Color(light:dark:) — so switching themes, or toggling system Dark Mode, repaints every screen live with no relaunch.

The background gradient

Two shapes, matching MuffinTheme.swift's backgroundGradient exactly:

  • Flat two-colour (every theme but one): backgroundTop → backgroundBottom, corner to corner — SwiftUI's .topLeading to .bottomTrailing, which is a 135° diagonal in CSS with the two colours spaced evenly.
  • Multi-stop (Autism Muffin only): a rainbow band straight down the screen — SwiftUI's .top to .bottom, 180° in CSS — spent in the top ~13% and holding a calm colour for the rest, so the header reads as a rainbow without turning every screen underneath it into one.

All 31 themes

Click any swatch to apply it — same shared theme picker as the button in the header, and the same 31 MuffinThemePresets.swift defines.

Pro themes

3 of the 31 — Diamond Ice, Gold VIP, and Holographic — are "Pro," unlocked by a code rather than gated behind an in-app purchase. There is no StoreKit product involved; the unlock code is the entire purchase path, and app icons are the only thing it gates — nothing else in MuffinEMU is paywalled. Codes are checked against a salted PBKDF2-HMAC-SHA256 hash embedded in the app, so no plaintext code appears anywhere in the source or the compiled binary; a successful unlock is then bound to a per-install random key so it survives reinstalls through the same signing identity without being copyable to a different install by just editing a preferences file.

Icons

31 app icons total — the original plus 30 alternates — each carrying the theme derived from its own artwork. Icon and theme pickers are deliberately independent: picking an icon never changes your theme, and picking a theme never changes your icon. A theme's association with "its" icon only ever shows up as a "matches your icon" label in the picker UI — nothing enforces pairing them.
