Save States

4 slots per game, alongside your normal in-game saves.

Limit

A save state only loads back into the same running game it was taken from. If you quit the game or the app, saves from before that point won't load, so use them as a checkpoint within one play session. Normal in-game saves are what carry progress between sessions.

Where they live

Each game gets its own folder, Documents/SaveStates/<game.id>/, with up to 4 files named slot1.sav through slot4.sav. Open the sheet from the in-game top bar. Each slot shows empty or when it was saved, with Save/Overwrite, Load and Delete actions.

What's saved

A save state stores the game's memory. It does not store graphics state, so after loading, a texture may briefly show its old picture until the game redraws it.

Saving pauses the game briefly. If no game is running, or the write fails, the save is reported as failed.
