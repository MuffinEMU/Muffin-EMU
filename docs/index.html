MuffinEMU

A Wii U emulator for iPhone and iPad, built on Cemu. Some MeloCafe cores and bug fixes have been brought over on top — the PowerPC interpreters, the AArch64 recompiler, the Metal and Vulkan renderers, and the iOS audio, input and window systems.

Get MuffinEMU View source on GitHub

🧁 Its own emulator

MuffinEMU grew out of Muffin, but the Cemu core underneath is maintained in this repo, with its own fixes and a curated set of upstream Cemu fixes on top. Own bundle identifier, own releases — it installs next to Muffin rather than replacing it.

🖥️ Metal-native renderer

The renderer is Metal, native to this port, with an optional Vulkan (MoltenVK) path. GPUs without mesh shader support emulate geometry shaders and RECTS primitives with compute passes, and decode BC-compressed textures on the CPU.

📖 Built in the open

Every crash and hang gets tracked and fixed as it's found, not papered over. This site says plainly what's confirmed on real hardware and what isn't — see Status below.

Status

Confirmed on an iPad Pro A12Z (iPad8,11). Said plainly, not oversold.

Confirmed

  • Boots real Wii U titles from an imported ROM library on real hardware
  • Metal renderer presents correctly on device
  • Multi-core PowerPC interpreter runs titles at a basic level

Still open

  • A full, confirmed playthrough of a retail title on this exact build — this page will say so plainly the day one lands, not before
  • Audio, controller input beyond the basics, and broad game compatibility — usable, not yet systematically verified
  • Dual-screen output to a genuine second display — written against the real API, never yet exercised with a display attached

Credits & license

Bring your own games and keys. No copyrighted content is distributed here — not games, not system files, not keys.

MuffinEMU is built on Cemu. Some MeloCafe cores and bug fixes have been brought over, from stossy11/MeloCafe. The optional melo-controls pad is Melo-Controller, also by stossy11 (GPL-3.0). The Vulkan path uses MoltenVK.

MuffinEMU's own source is MPL-2.0, like Cemu and MeloCafe. Because Melo-Controller (GPL-3.0) is linked into every build, a MuffinEMU IPA as a whole is distributed under GPL-3.0, with the repository above as its source.
