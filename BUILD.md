# Build instructions

[![MuffinEMU](https://img.shields.io/badge/MuffinEMU-Build-E5652E)](README.md) [Back to the README](README.md)

MuffinEMU builds for iOS only. The reference build is [`.github/workflows/build-ios-app.yml`](.github/workflows/build-ios-app.yml); the commands to run it by hand are in the README under [Building](README.md#building). [ARCHITECTURE.md](ARCHITECTURE.md) explains how the app, the bridge and the core fit together.

This repository still contains the desktop sources inherited from Cemu. For the upstream desktop build (Windows, Linux, macOS) see [Cemu's BUILD.md](https://github.com/cemu-project/Cemu/blob/main/BUILD.md).
