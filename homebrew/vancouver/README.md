# vancouver.rpx

A very coarse, hand-made flyover map of Metro Vancouver, BC for Wii U homebrew. A 40x30
cell grid in the source (water, land, North Shore mountains, Stanley Park) is drawn flat
with OSScreen, with labels for Vancouver, Burnaby, Richmond, Surrey, North Vancouver,
West Vancouver, Coquitlam, New Westminster, Delta and Stanley Park.

Controls (GamePad): left stick pans, right stick up/down zooms, A resets. The TV shows the
map; the GamePad shows a full-map mini-map with the current view box. Close the app to exit.

Map data (c) OpenStreetMap contributors, ODbL. The grid is hand-sketched with real
geography as reference; no OSM data files are included. Made by MuffinEMU.
